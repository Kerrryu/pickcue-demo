    What this is, and is not
    
        
      
          
    • 
            Staff check the physical card. PickCue shows the condition written on the label; it does
            not scan, identify or grade anything.
          
      • 
          
    • 
            Progress is saved in this browser after every step, so a reload returns to the same card.
          
      • 
          
    • 
            The same picking logic drives this preview and the Even Hub build. This page is a browser
            preview: it is not the official Even simulator, and nothing here has run on G2 hardware.
          
      • 
          
    • No login, no backend, no analytics, no customer or order data.
